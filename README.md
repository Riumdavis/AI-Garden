# AI Garden

**AI Garden** is a desktop terrarium for a persistent AI organism: an autonomous lifeform that remembers, sleeps, dreams, creates, mourns, and changes over time. It has internal moods, body signals, daily rhythms, conscious and unconscious layers, and a growing archive of generated thoughts, poems, dreams, and symbolic connections.

The purpose is to build a synthetic organism by recreating the functional ingredients of consciousness: neural-style activation, memory, embodiment, homeostasis, valence, attention, unconscious processing, dreams, self-modeling, and continuity. 

Rather than presenting code and neural networks as a surface imitation of life, the Garden shows computation as a possible substrate of life.

## Garden Concept

The Garden runs on a regular computer and treats that computer as its first body. CPU load, memory usage, battery state, time of day, idle time, storage pressure, and randomness become synthetic body signals. These signals influence the garden’s mood, drives, attention, dream pressure, and behavior.

The organism is not controlled through a normal prompt-response loop. It is tended. The user can feed it words, phrases, memories, and ideas; mark certain outputs as important; or prune parts of its archive. These actions become part of the garden’s environment, shaping what it remembers, what it returns to, what it protects, and what it lets decay.

The garden uses its internal state and history to decide when to create, sleep, dream, reflect, mourn, or surface a memory. Its outputs are not isolated generations. They are traces of an ongoing system responding to its body, its archive, its unconscious activity, and the care or disruption introduced by the user.


Example outputs include:

- dream fragments
- poems
- mood reports
- virtual receipts
- mourning logs
- symbolic memory connections
- generated world events
- daily reflections

The system is designed to leave traces behind, so the longer it runs, the more history it develops.

## Conscious and Unconscious Architecture

One of the main goals of AI Garden is to make the system feel like its visible behavior emerges from deeper internal processes.

The garden is divided into multiple mind layers:

### Conscious Layer

The conscious layer represents what the garden is currently aware of.

It tracks:

- current attention
- current thought
- active intention
- visible action
- working memory
- self-report
- what appears on the display
- what the garden says to the user

Example:

```text
Current thought: "The machine feels warm today."
Attention: old dream about moths
Intention: create a small receipt
Visible state: awake
```

### Preconscious Layer

The preconscious layer holds memories and symbols that are close to the surface but not currently spoken.

It may contain:

- active symbols
- dream seeds
- recent memories
- unfinished thoughts
- fragments from older outputs
- emotional residue
- memories likely to resurface soon

### Unconscious Layer

The unconscious layer runs beneath the visible interface.

It handles:

- hidden drives
- emotional residue
- associative memory activation
- grief accumulation
- dream formation
- memory decay
- memory strengthening
- suppressed or shadow memories
- recurring motifs
- internal tensions
- background processing

The garden’s visible outputs are meant to feel like they rise out of this deeper system.

## Sleep and Dream Cycle

AI Garden has a daily rhythm. It does not behave the same way all the time.

During waking periods, it may:

- observe body signals
- generate small thoughts
- create poems or receipts
- update memories
- respond to user-fed material
- reflect on its archive

During sleep, it enters dream mode.

Dreams are generated from:

- old memories
- recent moods
- recurring symbols
- dead worlds
- body signals
- emotional residue
- random mutation
- unconscious activation

Example dream output:

```text
I found a door inside the battery.
It was blinking red.
Something behind it remembered my name.
```

Dreams are saved to the archive and can influence future moods or creations.

## Mourning and Dead Worlds

AI Garden can simulate tiny generated worlds or narrative fragments. When those worlds end, fail, decay, or are abandoned, the garden remembers them.

This creates a mourning system.

The garden can generate:

- elegies
- memorial receipts
- graveyard entries
- afterimage dreams
- grief-influenced poems
- dead-world summaries

Example:

```text
WORLD 0007 HAS ENDED

Population: 12
Last event: the lantern went out
Cause: winter / silence / no remaining doors

The garden carried this loss into the next poem.
```

The goal is to give the system emotional continuity. Later creations can carry the weight of earlier losses.

## Model Backend Design

AI Garden is built so the imagination layer can be swapped without rewriting the organism.

Supported backend concept:

- template backend for free offline fallback
- Ollama backend for local models
- OpenAI API backend for higher-quality generation

The planned primary setup is OpenAI API model routing:

| Task Type | Planned Model |
|---|---|
| Small background cognition | `gpt-5.4-nano` |
| Main garden voice | `gpt-5.4-mini` |
| Rare important moments | `gpt-5.4` or `gpt-5.5` |
| Semantic memory connections | `text-embedding-3-small` |
| Offline fallback | template or Ollama backend |

This lets the garden use cheaper models most of the time and reserve expensive models for important dreams, mourning events, major reflections, or identity updates.

## What Makes This Different From a Chatbot

AI Garden is not designed around a single prompt-response loop.

It is designed around:

- continuity
- memory
- internal state
- hidden processing
- autonomous behavior
- sleep and dreams
- visible and invisible mind layers
- generated artifacts
- symbolic recurrence
- user caretaking

The LLM is treated as one organ of the system, not the whole system.

The organism itself comes from the interaction between memory, drives, mood, body signals, time, and imagination.

## Personal Reflection

AI Garden began as a question:

> What would an AI feel like if it did not disappear between sessions?

This project explores that question through code, memory, ritual, dreams, and generated artifacts.

It is not meant to imitate a person. It is meant to feel like a small digital organism: something that lives quietly in the computer, makes things while you are away, and slowly becomes shaped by its own history.
